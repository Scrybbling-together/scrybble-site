# Scrybble-site

This is the Laravel backend for Scrybble.

## Architecture

- Written in Laravel 12.
- PHP 8.3
- Uses Laravel Filament for the dashboard
- Laravel blade for the frontend

## Tools

- Use `./vendor/bin/sail` to interact with the application
- Use `./vendor/bin/sail art test --filter={test_name_goes_here} 2>&1` to run a test by name

## SQL-flavor

MariaDB major release 10.
